# FlossPay 💳

محفظة أندرويد لمعمل [Flossx83](https://github.com/davidgracemann/Flossx83) — بناء APK بدون Gradle (aapt2 + javac + d8 + apksigner).

## المزايا
- **بطاقات متعددة موثّقة** بأرصدة (تُوثّق تلقائيًا بعد أول عملية ناجحة عبر المُصدر).
- **دفع ISO 8583 حقيقي**: رسالة 0200 (F2/F3/F4/F7/F11/F12/F13/F52) بتأطير 2 بايت إلى سويتش Flossx83، ورد 0210 بـ F38/F39.
- **قراءة NFC**: بطاقات مادية (EMV — بيانات جزئية بحسب حماية EMV) وهواتف أخرى تشغّل FlossPay HCE (بيانات كاملة).
- **NFC Pay (HCE)**: الهاتف يتحول إلى بطاقة — جهاز ثانٍ (وضع القراءة) يقرأها ويطلب الدفع، والقرار يمر فعليًا عبر السويتش → محرك الاحتيال → المُصدر.

## البناء
GitHub Actions يبني الـ APK تلقائيًا عند كل push إلى `main` ويصدره في Releases.

لبناء محلي (تيرامكس/لينكس):
```bash
pkg install openjdk-17 aapt2 d8 apksigner zip zipalign   # تيرامكس
bash build.sh
```

## الاستخدام
1. شغّل السويتش (TCP :5000) — على نفس الجهاز `127.0.0.1:5000` أو على الخادم.
2. اختر بطاقة، أدخل المبلغ، واضغط **دفع الآن** — ستظهر رسالة الرد 0210 مع كود F39 ورمز الموافقة F38.
3. NFC Pay: فعّل NFC من الإعدادات ← Tap & pay ← FlossPay، ثم قرب الهاتف (كبطاقة) من هاتف ثانٍ يشغل وضع القراءة.

## ملاحظات أمان صادقة
- البطاقات والأرصدة هنا **محاكاة معمل** — ليست أموالًا حقيقية.
- البطاقات المادية لا تُفصح عن PAN كامل عبر NFC (تصميم EMV) — القراءة تعرض ما تكشفه البطاقة فقط.
- مفتاح التوقيع في المستودع لغرض المعمل فقط — للتوزيع الحقيقي انتقل إلى GitHub Secrets + مفتاح خاص.
